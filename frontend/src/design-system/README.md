RecuRight Design System

This folder contains a lightweight design-system reference and a showcase page.

Tokens
- `src/styles/design-tokens.css`: Centralized CSS variables for colors, spacing, radii and motion.

Component usage
- Use existing components under `src/components/ui` (Button, Input, Card, Modal, Select, Badge, LandingCard).
- Components are wired to the global CSS tokens via `globals.css` import.

How to preview
- Start the dev server and open `/design-system` to see the components and tokens in action.
